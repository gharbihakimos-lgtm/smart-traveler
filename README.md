# SmartStay Premium

Une application web interactive pour générer des séjours sur mesure à l'aide de l'Intelligence Artificielle.

## Fonctionnalités (MVP)
- 🤖 Assistant conversationnel IA (Mode Simulation ou Mode API Gemini)
- 🗺️ Carte interactive avec Leaflet
- 🏨 Base de données fictive avec algorithme de scoring intelligent
- 🔗 Liens dynamiques d'affiliation vers Booking.com

## Lancement local
```bash
npm install
npm run dev
node server.js
```
